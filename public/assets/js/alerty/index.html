Vanilla JavaScript · 0 dependencies · v1.2

Popup ablakok. Teljes kontroll.

Minden megnyitott ablak külön azonosítót kap. Kezeld őket egyenként, állítsd a footert, köss hozzá saját eseményeket — és válts témát azonnal.

Egyszerű alert

Megnyitás, láncolható beállítások, saját Mentés és Bezárás események.

Confirm ablak

Megerősítés ok/mégse callback függvényekkel.

Egyedi HTML footer

Bármilyen HTML a footerbe, data-name alapú eseménykezeléssel.

Több popup egyszerre

Nyiss több ablakot; mindegyiket külön azonosító alapján éred el.

set() és módosítás

Állítsd a címet, méretet, tartalmat és a működési opciókat.

Bezárás azonosítóval

Az utolsó popup lekérése és bezárása vagy az összes bezárása.

Message értesítések

Új értesítés az előző alá kerül, típusonként saját SVG ikonnal.

Eseménynapló
